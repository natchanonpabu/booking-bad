# Venue Facts

**สถานะ: ค่าเริ่มต้นของเดโม รอยืนยันจากสนามจริง** ยังไม่มีสนามนำร่องที่เซ็นแล้ว (ผู้ก่อตั้งทำเดโมก่อนเพื่อนำไปเสนอ) ค่าในไฟล์นี้จึงยังไม่ใช่ข้อเท็จจริงที่เจ้าของสนามลงนาม เมื่อได้คุยกับสนามจริงให้กรอกช่อง "คำตอบจริง" และลงนามด้านล่าง

**หลักการ (ตัดสินแล้ว 2026-10-07):** ค่าของสนามทุกข้อ (จำนวนคอร์ท, เวลา, ราคา, พีก, สภาพคอร์ท, ข้อมูลสนาม, นโยบายยกเลิก, VAT) **เก็บเป็นข้อมูลใน DB ไม่ฝังในโค้ด** หน้าแก้ในแอปมีเฉพาะ owner console 4 หน้าจอ ส่วนที่เหลือแก้ผ่าน seed/SQL ใน v1

ข้อเท็จจริงของสนามนำร่อง กรอกจากการสัมภาษณ์เจ้าของสนาม แล้วให้เจ้าของลงนาม

- สนาม: ______________________  สาขา: ______________________
- ผู้ให้ข้อมูล: ______________________  วันที่สัมภาษณ์: ____/____/____
- ลงนามเจ้าของสนาม: ______________________  วันที่: ____/____/____

**วิธีใช้คอลัมน์:**
- **ค่าเดโม** = ค่าที่ mockup/เดโมใช้อยู่ตอนนี้ (ให้เจ้าของยืนยันหรือแก้)
- **ค่าเริ่มต้นถ้าเกิน 3 วันทำงาน** = กฎ roadmap: ข้อไหนค้างเกิน 3 วันทำงาน ให้ผู้ตัดสินเลือกตัวเลือกที่ลบ schema ได้มากที่สุด (ผมเติมไว้เป็นข้อเสนอ ผู้ตัดสินแก้ได้)
- **คำตอบจริง** = กรอกหลังคุย เมื่อกรอกแล้วให้อัปเดตแถวที่ตรงกันใน `audit/register.md`
